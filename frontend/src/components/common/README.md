# Common Reusable UI Components
Components to be implemented:
- `Button.tsx`: Stylized buttons with variant (primary, secondary, danger, ghost), size, loading state
- `Card.tsx`: Dark navy card container with subtle borders
- `Badge.tsx`: Color-coded badges for statuses (Low Risk, High Risk, Active, Pending)
- `Modal.tsx`: Accessible dialog modal with backdrop
- `DataTable.tsx`: Searchable, filterable, paginated table
- `Input.tsx`: Form input fields with validation error feedback
